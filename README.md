### MP2: Responsive Restaurant Website::

Restaurant: Mezban Ghor (Chattogram-style). Built with HTML + Tailwind CSS (CDN).
Open index.html in a browser. Click Highlight requirements (bottom-right) to see each requirement outlined.

| # |Requirement | Where it is met |

| 1 |
Navigation bar + at least two content sections | Sticky `<header>` nav; sections: Hero, Menu, About (+ Reserve) |
| 2 |
Tailwind styling (colors, spacing, typography) | Custom colors/fonts in `tailwind.config`; classes like `bg-ink`, `text-turmeric`, `font-display`, `py-20`, `gap-6` |
| 3 |
Responsive for mobile and desktop | Hamburger menu below `md`; menu grid `grid-cols-1 sm:grid-cols-2 lg:grid-cols-3` |
| 4 |
At least one interactive element | Nav hover underline, hamburger toggle, menu category filter, card hover, reservation form |
